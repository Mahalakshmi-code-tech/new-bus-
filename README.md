# 🚍 SmartBus — Kinetic Intelligence for Modern Urban Transit

> **Move Smarter. Travel Better.**

SmartBus is a modern web-based Bus Management and Transit Platform designed to make urban transportation smarter, more connected, and easier to manage.

It brings bus tracking, route planning, transit alerts, analytics, AI assistance, and digital passenger services together in one unified platform.

🔗 **SmartBus:** https://new-bus-mauve.vercel.app/

## ✨ Features

### 🏠 Home
A modern landing experience introducing the SmartBus platform and its core capabilities.

### 🚌 Track Bus
- Bus search
- Simulated live bus movement
- Current bus information
- Next stop
- Estimated arrival time
- Occupancy / crowd information
- Smart Stop Alert
- Active Fleet view

> **Note:** Current bus movement is simulated for demonstration purposes.

### 🗺️ Smart Route Planner
- Select starting point and destination
- Explore available routes
- Compare route information
- View ETA
- View number of stops
- Check route status
- Explore route details

### 🔔 Smart Notifications
- Bus approaching alerts
- Delay alerts
- Crowd alerts
- Stop alerts
- Route updates
- Read / unread notifications
- Notification filtering

### 🤖 AI Co-Pilot
An AI-assisted interface for asking questions and understanding available SmartBus transit information.

### 📊 Transit Analytics
Provides an overview of available transit data such as:

- Active fleet
- Route activity
- Occupancy
- Fleet status
- Alerts
- Route performance

### 🎫 Digital Bus Pass
A passenger-focused digital pass interface containing:

- Pass information
- Route
- Validity
- Passenger details
- Pass status
- QR-style visual
- Pass actions

> **Note:** Current digital pass functionality is a frontend/demo experience. Real payment and ticket validation are not currently implemented.

### 🔎 Smart Search
Quickly search available buses, routes, and stops.

### 🌗 Light / Dark / Auto Theme
Choose between:

- ☀️ Light
- 🌙 Dark
- 💻 Auto

### 📖 How to Use
An interactive guide helps first-time users understand how to:

- Find routes
- Track buses
- Check alerts
- Use AI Co-Pilot
- Explore SmartBus features
